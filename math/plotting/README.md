# Plotting

Introduction to plotting with `matplotlib`: line graphs, scatter plots,
logarithmic scales, histograms, subplots and stacked bar graphs.

## Files

| File | Description |
| --- | --- |
| `0-line.py` | Plots `y = x^3` as a solid red line for `x` in `[0, 10]` |
| `1-scatter.py` | Scatter plot of men's height vs weight in magenta |
| `2-change_scale.py` | Exponential decay of C-14 with a log-scaled y-axis |
| `3-two.py` | Decay of C-14 (dashed red) and Ra-226 (solid green) with a legend |
| `4-frequency.py` | Histogram of student grades with bins every 10 units |
| `5-all_in_one.py` | All five previous plots in one 3 x 2 figure |
| `6-bars.py` | Stacked bar graph of fruit per person |

## Requirements

- Ubuntu 16.04 LTS, `python3` (3.5)
- `numpy` 1.15, `matplotlib` 3.0
- Code follows `pycodestyle` (2.5)
